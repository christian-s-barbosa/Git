# .gitattributes

## O que é?

O `.gitattributes` é um arquivo de configuração que define **atributos por caminho** (arquivo ou pasta). Enquanto o `.gitignore` diz o que o Git deve **ignorar**, o `.gitattributes` diz **como** o Git deve tratar determinados arquivos.

É **versionado** e compartilhado com a equipe, garantindo comportamento igual para todos.

## Onde fica?

| Local | Escopo |
| --- | --- |
| `.gitattributes` (raiz) | Todo o repositório |
| `.gitattributes` (subpasta) | Apenas aquela pasta |
| `.git/info/attributes` | Somente o seu repositório local (não versionado) |

## Sintaxe

```
padrão atributos
```

Exemplos:

```
*.txt text
*.png binary
*.md diff=markdown
```

- O `padrão` funciona como no `.gitignore`.
- Os atributos definem o comportamento.

## Fim de linha (line endings)

Muito útil em equipes que usam Windows e Linux ao mesmo tempo (CRLF x LF).

```
# normaliza automaticamente no commit
* text=auto

# força LF em arquivos de código
*.sh text eol=lf

# força CRLF em arquivos do Windows
*.bat text eol=crlf

# trata como binário (não converte)
*.png binary
```

- `text`: normaliza o fim de linha.
- `eol=lf` / `eol=crlf`: define o fim de linha no working directory.
- `-text` ou `binary`: não faz conversão.

## Diferenças e merge

```
# trata como binário (não mostra diff de texto)
*.png -diff

# usa um driver de diff específico
*.md diff=markdown

# merge que junta as duas versões (ex.: changelogs)
CHANGELOG.md merge=union
```

- `-diff`: o Git não tenta mostrar diferenças de texto.
- `merge=union`: no conflito, mantém as linhas das duas versões.

## Linguist (GitHub)

Define como o GitHub classifica os arquivos (linguagem do repositório):

```
# não conta nas estatísticas de linguagem
docs/* linguist-documentation
vendor/* linguist-vendored

# marca como gerado
dist/* linguist-generated

# força uma linguagem
*.php linguist-language=PHP
```

## Exportar

```
# não incluir no git archive
tests/* export-ignore
.github/* export-ignore
```

## Exemplo completo

```
* text=auto

*.sh   text eol=lf
*.bat  text eol=crlf
*.png  binary
*.jpg  binary

CHANGELOG.md merge=union

dist/* linguist-generated
```

## Erros comuns

- **Criar o `.gitattributes` depois de já haver CRLF/LF misturado**: é preciso renomear/renormalizar (`git add --renormalize .`).
- **Achar que o `.gitattributes` afeta o passado**: ele vale a partir do próximo `add`.
- **Confundir com `.gitignore`**: um trata, o outro ignora.
- **Esquecer de versionar** o arquivo.

## Casos de uso

| Situação | Atributo |
| --- | --- |
| Equipe com Windows e Linux | `* text=auto` / `eol` |
| Tratar imagens como binário | `*.png binary` |
| Evitar ruído no merge de changelog | `merge=union` |
| Não contar `vendor/` como linguagem | `linguist-vendored` |
| Excluir testes de um `git archive` | `export-ignore` |
