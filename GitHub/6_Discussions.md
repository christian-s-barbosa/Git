# Discussions

## O que é?

**GitHub Discussions** é um **fórum de conversas** dentro do repositório, para perguntas, ideias e debates que **não são** bugs nem tarefas. Ajuda a comunidade a se organizar e reduz o ruído nas issues.

## Discussions x Issues

| Característica | Issue | Discussion |
| --- | --- | --- |
| Objetivo | Tarefa/bug rastreável | Conversa aberta |
| Tem estado | Aberta/fechada | Categoria + resposta aceita |
| Foco | Execução | Discussão/comunidade |
| Fecha? | Sim, ao concluir | Pode ser respondida/marcada |

## Categorias

As discussions são organizadas em **categorias** (configuráveis), por exemplo:

- **Announcements**: avisos oficiais.
- **General**: conversa geral.
- **Ideas**: sugestões.
- **Polls**: enquetes.
- **Q&A**: perguntas e respostas (com "resposta aceita").
- **Show and tell**: mostrar projetos.

## Recursos

- **Resposta aceita** (Q&A): marca a solução.
- **Reações** e **upvotes**.
- **Conversão**: transformar issue em discussion (e vice-versa).
- **Fixação** de tópicos importantes.

## Como usar

1. Ative em **Settings → Features → Discussions**.
2. Defina as categorias.
3. Crie tópicos e participe.
4. Marque respostas aceitas no Q&A.

## Erros comuns

- **Abrir bug como discussion** (deveria ser issue).
- **Usar issue para dúvida geral**, poluindo o rastreamento.
- **Não definir categorias**, virando bagunça.
- **Deixar discussões sem moderação**.

## Casos de uso

| Situação | Onde |
| --- | --- |
| Dúvida de uso | Discussion (Q&A) |
| Sugestão de funcionalidade | Discussion (Ideas) |
| Bug reproduzível | Issue |
| Anúncio de versão | Discussion (Announcements) |
| Debate de arquitetura | Discussion (General) |
